# 致敬與致謝

本站點 **ヴワル魔法図書館** 在構建過程中，深度吸收與結合了現代開源軟件領域諸多前沿的技術結晶。無論是極速的靜態構建系統、優雅細膩的排版交互，還是強大的閱讀增強套件，都離不開開源社區無私的奉獻。

我們在此謹向以下傑出的開源項目、其核心團隊以及全球所有貢獻者致以最崇高的敬意與由衷的謝意！

---

## 核心基石項目

### 1. VitePress
- **團隊與創作者**：Evan You（尤雨溪）及 VitePress 貢獻者團隊
- **官方網站**：[vitepress.dev](https://vitepress.dev/)
- **開源倉庫**：[vuejs/vitepress](https://github.com/vuejs/vitepress)
- **開源協議**：MIT License
- **致謝與作用**：本站文檔的系統架構、交互排版與核心內容均源自 VitePress 官方文檔。VitePress 重新定義了現代技術文檔的開發範式，憑藉極低的開銷和卓越的體驗，為全球開發者帶來了如同享受般的寫作與閱讀體驗。

### 2. Vue.js
- **團隊與創作者**：Evan You（尤雨溪）及 Vue.js 核心團隊
- **官方網站**：[vuejs.org](https://vuejs.org/)
- **開源倉庫**：[vuejs/core](https://github.com/vuejs/core)
- **開源協議**：MIT License
- **致謝与作用**：作為整套文檔應用的基礎框架，Vue 3 的 Composition API 和響應式系統賦予了文檔無限的動態擴展可能。

### 3. Vite
- **團隊與創作者**：Evan You（尤雨溪）及 Vite 團隊
- **官方網站**：[vite.dev](https://vite.dev/)
- **開源倉庫**：[vitejs/vite](https://github.com/vitejs/vite)
- **開源協議**：MIT License
- **致謝與作用**：下一代前端開發與構建工具，帶來毫秒級的熱更新（HMR）以及穩定高效的生產環境打包能力。

## 知識庫生態與增強插件

### 4. Nólëbase
- **創作者**：絢香猫 ([@nekomeowww](https://github.com/nekomeowww))、絢香音 ([@LittleSound](https://github.com/LittleSound)) 及社區
- **官方網站**：[nolebase.ayaka.io](https://nolebase.ayaka.io/)
- **開源倉庫**：[nolebase/nolebase](https://github.com/nolebase/nolebase) / [nolebase/integrations](https://github.com/nolebase/integrations)
- **開源協議**：MIT License
- **致謝與作用**：本項目的初始架構模板源自 Nólëbase。Nólëbase 開拓了基於 Obsidian 雙鏈與 VitePress 結合的數字化花園範式，提供了增強閱讀體驗（Enhanced Readabilities）、大綱聚光燈、內聯鏈接懸停預覽、Git 更新日誌分析等全套現代知識管理插件。

### 5. UnoCSS
- **團隊與創作者**：Anthony Fu（Anthony Fu）及社區
- **官方網站**：[unocss.dev](https://unocss.dev/)
- **開源倉庫**：[unocss/unocss](https://github.com/unocss/unocss)
- **開源協議**：MIT License
- **致謝與作用**：即時、高性能的原子化 CSS 引擎，賦予頁面組件純粹、輕量、高可定制的樣式表現力。

### 6. VueUse
- **團隊与創作者**：Anthony Fu（Anthony Fu）及 VueUse 貢獻者
- **官方網站**：[vueuse.org](https://vueuse.org/)
- **開源倉庫**：[vueuse/vueuse](https://github.com/vueuse/vueuse)
- **開源協議**：MIT License
- **致謝與作用**：提供剪貼板複製、狀態監聽等關鍵交互的組合式工具庫。

### 7. Markdown-it 生態
- **主要模塊**：`markdown-it`, `markdown-it-footnote` 等
- **開源協議**：MIT License
- **致謝與作用**：提供了扎實、可靈活擴展的 Markdown 語法樹解析與渲染能力。
