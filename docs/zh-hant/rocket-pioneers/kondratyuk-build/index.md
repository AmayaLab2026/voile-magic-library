# 第二編 · 致讀此書以建造者（孔德拉秋克第一手稿）
### To Whomsoever Will Read in Order to Build (1918–1919)
**尤里·瓦西裏耶維奇·孔德拉秋克（Yu. V. Kondratyuk）著**  
*蘇聯科學院自然科學與技術史研究所 整理考證*

---

## 手稿全貌與歷史淵源

《致讀此書以建造者》（*To Whomsoever Will Read in Order to Build*）是蘇聯航天先驅**尤里·瓦西裏耶維奇·孔德拉秋克**（真名：亞歷山大·伊格納季耶維奇·沙爾熱，Aleksandr Ignat'yevich Shargey，1897–1942）現存最早的航天理論手稿。該手稿初撰於 1918 至 1919 年俄國內戰與動盪的艱苦歲月，彼時年輕的作者隱居於烏克蘭波爾塔瓦及西伯利亞邊陲，在完全與外界學術界隔絕、手頭缺乏科學文獻與實驗儀器的極端環境下，憑藉着驚人的天才直覺與嚴密的古典力學推導，獨立創立了航天動力學與星際飛行的宏偉技術體系。

手稿在孔德拉秋克生前未曾正式出版，僅在親友與極少數學者間傳閱。直至 1938 年，孔德拉秋克將其手稿原件鄭重託付並寄贈給蘇聯科學院；衛國戰爭爆發後，孔德拉秋克毅然投筆從戎，於 1942 年壯烈犧牲在莫斯科近郊保衛戰的前線戰場。1964 年，蘇聯科學院自然科學與技術史研究所將該第一版手稿的原始全貌整理編纂入《火箭技術先驅：選集》，並隨後由美國國家航空航天局（NASA）組織翻譯爲英文官方文獻（NASA TT F-9285）。

## 曠世技術預見的里程碑

在這部寫於人類甚至尚未製造出真正現代液體火箭的早期手稿中，孔德拉秋克以不可思議的遠見，首次提出了人類此後半個世紀載人航天所遵循的全部核心基石：

1. **火箭運動方程與引力損失修正**：獨立於齊奧爾科夫斯基推導了變質量火箭理想速度公式，並率先引入重力加速度時間積分對推進劑指數的懲罰因子（$1 + \frac{1}{k-1}$）。
2. **人體抗過載液體浸泡方案（抗過載浴缸）**：首次從流體靜力學平衡角度論證了宇航員浸泡在與人體等密度的液體密閉容器中，能夠抵禦數倍甚至數十倍於常規極限的機械加速度。
3. **高能推進劑與離子推進**：系統探討了液氫與液氧的巨大熱值，並開創性地設想利用電能將原子轉化爲陰極射線（電子流/高速離子流）噴射推進，成爲當代電推進與離子發動機的最初源頭。
4. **多級火箭結構與貯箱拋棄**：提出了沿航程逐步分離拋棄空推進劑貯箱以大幅降低死重比（即多級火箭）的具體機械構造方案。
5. **陀螺儀三軸慣性穩定定向**：設計了利用框架式萬向節密封陀螺儀與伺服操縱桿聯合控制火箭噴管偏轉的姿態控制系統。
6. **行星大氣層氣動減速滑翔再入（“尤里卡！”）**：劃時代地指出返回地球無需攜帶同等量級的逆噴推進劑，而是利用帶翼滑翔外形切入行星稀薄大氣層，依靠空氣氣動阻力將數十馬赫的軌道動能平緩耗散爲熱能，從而節約了高達 90% 以上的飛船起飛全重。
7. **空間太陽能聚光反射鏡與軌道基地**：設想在近地軌道部署輕質薄膜太陽能反射鏡，收集空間無盡輻射能並建立永久性載人軌道中繼站。
8. **雙天體引力彈弓助推與減速**：首次嚴格從分析幾何與天體力學角度證明，宇宙飛船掠過運動天體（如月球或其他行星）的引力場時，能夠“借用”天體的軌道公轉動能使自身加速或減速，成爲今日深空探測器（如旅行者號、卡西尼號、新視野號）標配的引力助推航線。
9. **電磁軌道發射炮（質量投擲器）**：提出了利用長距離多級通電銅管線圈電磁加速發射航天彈丸的設想。

## 章節閱讀導引

本選集第二編嚴格遵循 NASA TT F-9285 英文原版及莫斯科十月革命中央國家檔案館原始手稿，分章單列全譯如下：

* **[第一章：噴氣推進基本原理與理想速度方程](./section-1.md)**（P18–P22）  
  *探討太空航行的基本準則、常規大炮與拋石機的物理侷限、反作用推力公式推導、地球引力位能與人體/飛船機械加速度極限。*
* **[第二章：軌道爬升方案、抗過載與活性推進劑](./section-2.md)**（P23–P27）  
  *詳述沿近地環繞軌道爬升以平衡引力的第二種飛行方法、宇航員抗過載液體浴缸方案、推進劑化學反應熱與陰極射線（離子推進）設想。*
* **[第三章：飛船結構、多級分離與陀螺定向](./section-3.md)**（P28–P33）  
  *解析飛船剖面構造、加速度下貯箱受力計算、空貯箱逐級分離結構（多級火箭）以及陀螺儀三軸慣性定向機構與操縱系統。*
* **[第四章：噴管設計、天體定向與返回發現](./section-4.md)**（P34–P38）  
  *研究拉伐爾拋物面膨脹噴管截面方程、工質相變汽化傳熱、潛望式天體定向儀，以及利用大氣層氣動減速降落的“尤里卡”靈感誕生。*
* **[第五章：滑翔再入、大氣制動與熱防護](./section-5.md)**（P39–P41）  
  *深入計算返回地球的三種推進劑能耗差異、倒裝飛船與帶翼滑翔再入機體外形，以及高超聲速再入滑翔的傾斜姿態與氣動防熱。*
* **[第六章：太空太陽能反射鏡、引力彈弓與軌道基地](./section-6.md)**（P42–P51）  
  *探討太空超輕薄膜太陽能聚能鏡、近地軌道人造衛星補給基地、利用行星引力場助推/減速的力學原理，以及多級電磁發射炮。*
* **[編委會文獻考證與技術評註](./commentary.md)**（P52–P59）  
  *收錄蘇聯科學院航天遺產編委會對手稿歷史年代、力學符號、熱力學計算與優先權考證的 28 項詳盡學術評註與附圖。*
