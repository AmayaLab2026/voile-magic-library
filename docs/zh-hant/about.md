## 🏛️ 這裡是一座怎樣的圖書館？

**ヴワル魔法図書館**（Voile Magic Library / 伏瓦魯魔法圖書館）最初得名於幻想鄉紅魔館地下那座不見天日、浩瀚無垠的古典魔導大書庫。在魔女與學者的低語守護下，數以萬計記載著世界本質秘密的羊皮紙與古籍在此長眠。

而在現代數位化花園的語境下，本館由 **AmayaLab** 創設並由館長**翎奈貓**主持維護，是一座**致力於沉澱跨學科“硬核學術與禁忌前沿知識”的開源數位典籍館**。

我們不隨波逐流於淺嚐輒止的快餐資訊，而是將目光投向那些橫跨在**高級有機化學、精神藥理學（Psychopharmacology）、法庭毒理物證學、開源情報學（OSINT）以及人類社會法律規制邊界**上的深度文獻。
