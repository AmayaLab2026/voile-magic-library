# 第十二章 · 字体设计与编辑实操
### Chapter 12: Creating and Modifying Fonts
**著者：雅尼斯·哈拉兰布斯 博士（Yannis Haralambous, Ph.D.）**  
*选自《字体与编码》（Fonts & Encodings）原著第 445–506 页*

---

在数字字体工程的核心领地，拥有一款得心应手的专业字体编辑器（Font Editor），是排印师将灵感草图蜕变为工业级字库文件的唯一桥梁。

当今数字造字领域早已脱离了单纯手工绘制点阵的蛮荒时代。字体设计是一场严苛的几何学实验：它要求设计师在千分之几的网格精度内，操控精密的贝塞尔曲线，并在字符编码映射（Encoding）、矢量轮廓拓扑（Outlines）、排印度量间隙（Metrics）、复合字形组装（Composites）以及高级排版特性之间构筑起完美的数学平衡。

---

## 现代数字字体设计工业软件全景

在二十一世纪初的字体工程界，形成了以商业巨擘与开源领袖并立的经典格局：

* **FontLab Studio（Fontlab Ltd.）**：跨平台（macOS / Windows）的工业级标准字库制作软件。它兼具极其精湛的贝塞尔曲线绘制工具箱、完备的 OpenType 特性定义语言编译器、以及业界唯一的交互式 TrueType 指令调试器；
* **FontForge（George Williams 创立）**：Unix / X Window 与开源社区的传世丰碑。完全免费开源，由乔治·威廉姆斯（George Williams）以惊人的数学才华与工程耐力独力写就。FontForge 不仅原生支持几乎全人类所有已知字体格式（从古典 BDF、Type 1 到 OpenType 和 Apple AAT），还内建了极其强悍的 Python 批处理脚本引擎；
* **Fontographer 与 DTL FontMaster**：早期桌面出版时代的先驱者，在字形轮廓插值与多主控（Multiple Master）字体生成领域奠定了深厚的方法论基础。

## 曲线的数学之争：三次与二次贝塞尔样条

在数字轮廓字体的设计中，存在着两条截然不同的数学流派：**Adobe PostScript 阵营的三次贝塞尔曲线（Cubic Bézier）** 与 **Apple / Microsoft TrueType 阵营的二次贝塞尔样条（Quadratic Bézier Splines）**。

### 1. 三次贝塞尔曲线（PostScript Type 1 / OpenType CFF）
三次贝塞尔曲线由起点 $\mathbf{P}_0$、终点 $\mathbf{P}_3$ 以及**两个独立的离线控制点（Off-curve control points）** $\mathbf{P}_1$ 和 $\mathbf{P}_2$ 唯一定义：
$$\mathbf{B}(t) = (1-t)^3 \mathbf{P}_0 + 3(1-t)^2 t \mathbf{P}_1 + 3(1-t) t^2 \mathbf{P}_2 + t^3 \mathbf{P}_3, \quad t \in [0, 1]$$
* **优势**：单条曲线内部即可自由实现**拐点（Inflection Point）**与 $S$ 形反向弯曲；控制点处的一阶与二阶导数调节极其符合书法艺术家的直觉，能用极少节点勾勒出优雅顺滑的弧线；
* **标准设计网格**：通常采用 **1000 UPM（Units Per Em）** 的整数网格。

### 2. 二次贝塞尔样条（TrueType / OpenType TTF）
二次贝塞尔曲线仅由起点 $\mathbf{P}_0$、终点 $\mathbf{P}_2$ 以及**一个离线控制点** $\mathbf{P}_1$ 决定：
$$\mathbf{B}(t) = (1-t)^2 \mathbf{P}_0 + 2(1-t) t \mathbf{P}_1 + t^2 \mathbf{P}_2, \quad t \in [0, 1]$$
* **数学特质**：二次曲线的曲率符号是恒定的，**单段二次曲线绝不可能出现拐点！** 为了拟合一条平滑的 $S$ 形曲线，TrueType 必须将多个二次弧段首尾串联；
* **隐式中点规则（Implicit On-curve Points）**：为了极大地压缩文件体积，TrueType 规范引入了精妙的隐式点机制——**当两个离线控制点连续出现时，图形光栅化引擎会自动在它们二者的几何中点处插入一个处于曲线上的隐式在线节点**；
* **标准设计网格**：通常采用 **2048 UPM** 的二进制幂整数网格，以换取极高的坐标精度。

## 轮廓拓扑学：绕行方向与内外环判定

字形轮廓不仅仅是一串离散的控制点坐标，更是一个由闭合回路构成的二维流形。在字体格式中，**轮廓的遍历方向（Contour Direction）主宰着像素填充算法的生死！**

*图 12-11：拉丁字母 ‘o’ 的轮廓遍历方向对比（选自原著 Figure 12-11）。左侧 PostScript 格式遵循外轮廓逆时针（CCW）、内轮廓顺时针（CW）规则；右侧 TrueType 格式严格相反，外轮廓顺时针（CW）、内轮廓逆时针（CCW）。*

### 1. 非零环绕数规则（Non-Zero Winding Rule）
现代光栅化引擎（Rasterizer）在决定一个物理屏幕像素是否需要着墨变黑时，采用**非零环绕数测试（Non-Zero Winding Number Rule）**：
1. 从待判定的屏幕点向无穷远发射一条射线；
2. 射线每穿过一条从左至右穿过的轮廓线段，环绕计数器 $+1$；
3. 射线每穿过一条从右至左穿过的轮廓线段，环绕计数器 $-1$；
4. 若最终累计计数器不等于 $0$，则该点处于字形“内部”，予以着色；若等于 $0$，则判定为空心字怀，保留空白背景。

若排印师在绘制字母 `O` 时不慎将内圈字怀的绕行方向画反（与外圈方向同向），射线穿过两次同向线段后计数器为 $+2 \neq 0$，字母 `O` 中心的空洞将瞬间被黑墨彻底填死！专业编辑器均内建了“纠正轮廓方向（Correct Contour Direction）”算法，通过计算闭合多边形的格林公式面积符号自动纠正遍历顺序。

## 字形度量与高级字距微调（Kerning）

绘制完完美的矢量曲线，仅仅完成了字体工程的一半。字形在文本流中的物理定位，由严密的度量系统（Metrics）支配：

### 1. 水平排版度量五元组
对于每一个字形，排印师必须精确标定五项关键度量参数：
* **字身宽 / 水平进距（Advance Width, AW）**：排字机或排版引擎在输出该字形后，光标沿 X 轴向右移动的物理距离；
* **左侧轴承 / 左字边距（Left Sidebearing, LSB）**：字形原点 $(0, 0)$ 到字形轮廓最左侧极值点之间的水平留白空隙；
* **右侧轴承 / 右字边距（Right Sidebearing, RSB）**：字形轮廓最右侧极值点到下一个字形原点之间的水平空隙；
* **字形外框边界盒（Bounding Box, BBox）**：包围字形所有贝塞尔控制点的最小矩形 $[x_{\min}, y_{\min}, x_{\max}, y_{\max}]$；
* **基线（Baseline）**：$y = 0$ 的水平参考线，大写字母与小写字母主干底部均沉着于此。

### 2. 基于类的字距微调（Class-based Kerning）
在排版由特定字母构成的字对时（如 `AV`、`Ta`、`To`、`W.`），单纯依靠固定的字边距会导致它们之间产生巨大的视觉空洞。排印师必须向字体中注入**字距微调（Kerning）修正量**。

在早期的点对微调（Pair Kerning）中，字库必须为每一对字符记录一个修正数值。这在涵盖数千字符的多语言大字库中会导致组合爆炸（$N$ 个字符会产生 $N^2$ 对组合，文件体积膨胀数十倍）。

现代字体工程全面采用**基于类的字距微调（Class-based Kerning）**：
* 将视觉外轮廓右侧几何形态相似的字形归为同一个左侧类（Left Class），例如将 `A`, `À`, `Á`, `Â`, `Ã`, `Ä`, `Å` 归为 `@_A_LEFT`；
* 将外轮廓左侧相似的字形归为右侧类（Right Class），例如将 `V`, `W`, `Y` 归为 `@_V_RIGHT`；
* 排印师仅需定义一条类规则：
  ```
  pos @_A_LEFT @_V_RIGHT -90;
  ```
  排版引擎便会自动为这数十个重音变体与斜体字母瞬间应用精准的 $-90$ 单位收紧微调！

## 自动矢量追踪（Autotracing）算法原理解密

当排印师需要将纸面书法手稿或历史珍本扫描件导入编辑器时，自动描摹矢量化（Autotracing）技术扮演着核心角色。在 FontForge 与 ScanFont 中，广泛集成了由 Peter Selinger 开发的著名数学工具 **Potrace**：

1. **二值化与多边形轮廓抽取**：利用 Bresenham 算法将栅格位图转化为高精度的像素折线多边形；
2. **多边形最优顶点降采样**：基于动态规划算法（Dynamic Programming），在保证误差绝对不超过容差阈值 $\varepsilon$ 的前提下，寻找顶点数量最少的等效逼近多边形；
3. **贝塞尔曲线最小二乘拟合**：在每一个平滑转角处，求解高斯正规方程组，自动计算出均方根误差最小的三次贝塞尔控制点坐标；
4. **平滑点与尖角点拓扑判定**：通过分析曲线曲率极值点与一阶导数夹角，精准识别出哪些节点应标记为共线平滑点（Smooth Point），哪些节点应保留为锐利的尖角折点（Corner Point）。
