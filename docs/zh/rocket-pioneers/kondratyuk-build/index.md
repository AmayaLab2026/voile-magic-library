### To Whomsoever Will Read in Order to Build (1918–1919)
**尤里·瓦西里耶维奇·孔德拉秋克（Yu. V. Kondratyuk）著**  
*苏联科学院自然科学与技术史研究所 整理考证*

## 手稿全貌与历史渊源

《致读此书以建造者》（*To Whomsoever Will Read in Order to Build*）是苏联航天先驱**尤里·瓦西里耶维奇·孔德拉秋克**（真名：亚历山大·伊格纳季耶维奇·沙尔热，Aleksandr Ignat'yevich Shargey，1897–1942）现存最早的航天理论手稿。该手稿初撰于 1918 至 1919 年俄国内战与动荡的艰苦岁月，彼时年轻的作者隐居于乌克兰波尔塔瓦及西伯利亚边陲，在完全与外界学术界隔绝、手头缺乏科学文献与实验仪器的极端环境下，凭借着惊人的天才直觉与严密的古典力学推导，独立创立了航天动力学与星际飞行的宏伟技术体系。

手稿在孔德拉秋克生前未曾正式出版，仅在亲友与极少数学者间传阅。直至 1938 年，孔德拉秋克将其手稿原件郑重托付并寄赠给苏联科学院；卫国战争爆发后，孔德拉秋克毅然投笔从戎，于 1942 年壮烈牺牲在莫斯科近郊保卫战的前线战场。1964 年，苏联科学院自然科学与技术史研究所将该第一版手稿的原始全貌整理编纂入《火箭技术先驱：选集》，并随后由美国国家航空航天局（NASA）组织翻译为英文官方文献（NASA TT F-9285）。

## 旷世技术预见的里程碑

在这部写于人类甚至尚未制造出真正现代液体火箭的早期手稿中，孔德拉秋克以不可思议的远见，首次提出了人类此后半个世纪载人航天所遵循的全部核心基石：

1. **火箭运动方程与引力损失修正**：独立于齐奥尔科夫斯基推导了变质量火箭理想速度公式，并率先引入重力加速度时间积分对推进剂指数的惩罚因子（$1 + \frac{1}{k-1}$）。
2. **人体抗过载液体浸泡方案（抗过载浴缸）**：首次从流体静力学平衡角度论证了宇航员浸泡在与人体等密度的液体密闭容器中，能够抵御数倍甚至数十倍于常规极限的机械加速度。
3. **高能推进剂与离子推进**：系统探讨了液氢与液氧的巨大热值，并开创性地设想利用电能将原子转化为阴极射线（电子流/高速离子流）喷射推进，成为当代电推进与离子发动机的最初源头。
4. **多级火箭结构与贮箱抛弃**：提出了沿航程逐步分离抛弃空推进剂贮箱以大幅降低死重比（即多级火箭）的具体机械构造方案。
5. **陀螺仪三轴惯性稳定定向**：设计了利用框架式万向节密封陀螺仪与伺服操纵杆联合控制火箭喷管偏转的姿态控制系统。
6. **行星大气层气动减速滑翔再入（“尤里卡！”）**：划时代地指出返回地球无需携带同等量级的逆喷推进剂，而是利用带翼滑翔外形切入行星稀薄大气层，依靠空气气动阻力将数十马赫的轨道动能平缓耗散为热能，从而节约了高达 90% 以上的飞船起飞全重。
7. **空间太阳能聚光反射镜与轨道基地**：设想在近地轨道部署轻质薄膜太阳能反射镜，收集空间无尽辐射能并建立永久性载人轨道中继站。
8. **双天体引力弹弓助推与减速**：首次严格从分析几何与天体力学角度证明，宇宙飞船掠过运动天体（如月球或其他行星）的引力场时，能够“借用”天体的轨道公转动能使自身加速或减速，成为今日深空探测器（如旅行者号、卡西尼号、新视野号）标配的引力助推航线。
9. **电磁轨道发射炮（质量投掷器）**：提出了利用长距离多级通电铜管线圈电磁加速发射航天弹丸的设想。

## 章节阅读导引

本选集第二编严格遵循 NASA TT F-9285 英文原版及莫斯科十月革命中央国家档案馆原始手稿，分章单列全译如下：

* **[第一章：喷气推进基本原理与理想速度方程](./section-1.md)**（P18–P22）  
  *探讨太空航行的基本准则、常规大炮与抛石机的物理局限、反作用推力公式推导、地球引力位能与人体/飞船机械加速度极限。*
* **[第二章：轨道爬升方案、抗过载与活性推进剂](./section-2.md)**（P23–P27）  
  *详述沿近地环绕轨道爬升以平衡引力的第二种飞行方法、宇航员抗过载液体浴缸方案、推进剂化学反应热与阴极射线（离子推进）设想。*
* **[第三章：飞船结构、多级分离与陀螺定向](./section-3.md)**（P28–P33）  
  *解析飞船剖面构造、加速度下贮箱受力计算、空贮箱逐级分离结构（多级火箭）以及陀螺仪三轴惯性定向机构与操纵系统。*
* **[第四章：喷管设计、天体定向与返回发现](./section-4.md)**（P34–P38）  
  *研究拉伐尔抛物面膨胀喷管截面方程、工质相变汽化传热、潜望式天体定向仪，以及利用大气层气动减速降落的“尤里卡”灵感诞生。*
* **[第五章：滑翔再入、大气制动与热防护](./section-5.md)**（P39–P41）  
  *深入计算返回地球的三种推进剂能耗差异、倒装飞船与带翼滑翔再入机体外形，以及高超声速再入滑翔的倾斜姿态与气动防热。*
* **[第六章：太空太阳能反射镜、引力弹弓与轨道基地](./section-6.md)**（P42–P51）  
  *探讨太空超轻薄膜太阳能聚能镜、近地轨道人造卫星补给基地、利用行星引力场助推/减速的力学原理，以及多级电磁发射炮。*
* **[编委会文献考证与技术评注](./commentary.md)**（P52–P59）  
  *收录苏联科学院航天遗产编委会对手稿历史年代、力学符号、热力学计算与优先权考证的 28 项详尽学术评注与附图。*
