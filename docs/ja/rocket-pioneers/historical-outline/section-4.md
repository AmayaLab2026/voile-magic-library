# 第4章：初期研究機関（GDL/GIRD/RNII）の総括と全編参考文献

*訳者：[Lycoris \<lycorismisaka@gmail.com\>](mailto:lycorismisaka@gmail.com)*

## 一、孤立せる理論先駆者から国家的研究集団へ（GDL、GIRD、RNII）

十月革命前の長き歳月において、ロシアの科学者たちはロケット推進理論の領域において世界の最前線に立ち続けていたものの、ツァーリ専制統治、それに続く苛烈なロシア内戦、外国軍の武装干渉、そして戦後初期の極めて困難な国民経済復興の渦中にあって、先駆者たちは科学的着想を大規模な工業的実践へと移行させるために不可欠な物質的条件や工業技術的基盤を長きにわたり欠いていました。

客観的に指摘せねばならないのは、F・A・ツァンダーが1920年代末に行った小規模な実験室エンジン試験を除き、わが国の第一世代ロケット先駆者たち（ツィオルコフスキー、コンドラチュクら）は基本的に極めて孤立した個人の書斎においてその理論的礎石を築いたのであり、彼らは科学的仮説の提示と数学的推導に甘んぜざるを得ず、恒常的な近代的実験研究基地を組織することは叶いませんでした。

歴史的転換は1920年代末から1930年代初頭にかけて訪れました。ソビエト国家による全面的な社会主義工業化の推進に伴い、分散・孤立していた先駆者個人の探究は、国家が直接組織・資金拠出を行う**専門的研究集団**へと急速に道を譲ることとなったのです：

### 1. 気体力学研究所（GDL / Газодинамическая лаборатория）
* **創設と発展**：1921年に卓越した化学者**ニコライ・イヴァノヴィチ・チホミーロフ（N. I. Tikhomirov, 1860–1930）**によってモスクワに創設。当初は軍事部発明研究所と呼称され、1927年にレニングラードへ移転、1928年に「気体力学研究所」（GDL）と正式命名されました；
* **固体火薬ロケット兵器の礎（カチューシャの揺籃）**：チホミーロフ、V・A・アルテミエフ、B・S・ペトロパヴロフスキー、そしてゲオルギー・エリホヴィチ・ランゲマク（G. E. Langemak）らの指導のもと、GDLは無煙コロイド火薬（ダブルベース火薬）を薄肉燃焼室内で高圧安定燃焼させる核心技術を世界で初めて突破。航空機の離陸補助ロケット、ならびに空対地・空対空戦闘用の成系列野戦固体ロケット弾を開発しました——これこそが第二次世界大戦で世界にその名を轟かせた**多連装ロケット砲「カチューシャ」（RS-82およびRS-132航空／陸用ロケット弾）の直接の技術的発祥地**であります！
* **液体および電気ロケットエンジンの開拓（グルシュコの研究開始）**：1929年5月、若き**ワレンチアン・ペトロヴィチ・グルシュコ（V. P. Glushko, 1908–1989）**はGDL内部にソ連史上初となる液体ロケットエンジンおよび電気推進ロケットエンジンの設計研究部門（第二部門）を組織しました。グルシュコ率いるチームは高名な **ORM シリーズ液体ロケットエンジン**（ORM-1からORM-65まで）を相次いで開発しました：
  * 高濃度**硝酸**、四酸化二窒素、液体酸素を酸化剤とし、**ケロシン（灯油）**やトルエンを燃料とする二元液体推進体系を世界に先駆けて実験検証；
  * **自己着火性（ハイパーゴリック）化学点火技術**、燃焼室内壁の**特殊耐熱セラミック断熱コーティング**、ならびに流体圧力循環による**二重壁再生冷却ノズル**を初めて開発・試射；
  * ソ連の将来の大推力液体運載ロケットエンジン学派の揺るぎなき工学的実験基盤を確立しました。

### 2. 反動推進研究グループ（GIRD / Группа изучения реактивного движения）
* **創設の背景**：1931年秋、ソ連国防・航空・化学建設促進会（オソアヴィアヒム）の指導のもと、モスクワ反動推進研究グループ（MosGIRD）とレニングラード反動推進研究グループ（LenGIRD）が相次いで正式発足しました；
* **指導陣**：モスクワGIRDはF・A・ツァンダーと**セルゲイ・パヴロヴィチ・コロリョフ（S. P. Korolev, 1907–1966）**が共同で指導にあたり、ユーリ・A・ポベドノスツェフ（Yu. A. Pobedonostsev）、ミハイル・K・チホンラヴォフ（M. K. Tikhonravov）ら気鋭の若き英才が集結しました；
* **歴史的飛行実験の突破**：
  * **ソ連初の打ち上げ成功液体（半液体／ハイブリッド）ロケット「GIRD-09」**：チホンラヴォフが設計を主導し、液体酸素を酸化剤、固化ガソリンとロジン（松脂）のゲルを燃料として採用。**1933年8月17日**、モスクワ郊外ナハビノにおいて打ち上げに成功し、高度400メートルに到達；
  * **ソ連初の全液体推進剤ロケット「GIRD-X」**：ツァンダーが基本設計を行い、彼の没後にコロリョフが最終完成させたロケット。液体酸素とアルコールを推進剤とし、**1933年11月25日**に打ち上げ成功、高度80メートルに到達しました。

### 3. ジェット推進科学研究所（RNII / Реактивный научно-исследовательский институт）
* **国家戦略的統合**：研究勢力の分散を克服するため、ソ連革命軍事会議副議長・重工業副人民委員M・N・トゥハチェフスキーの直接の主導により、ソビエト最高指導部は**1933年秋**、歴史的決定を下しました：**レニングラードGDLとモスクワGIRDを公式に統合し、世界初の国家総合ロケット研究機関であるジェット推進科学研究所（RNII / 第3研究所）を創設したのです**；
* **指導体制**：初代所長にはイヴァン・テレンチエヴィチ・クレイメノフ（I. T. Kleymenov）、副所長兼技師長にG・E・ランゲマク、コロリョフが副所長および有翼ロケット滑空機設計主任に就任；
* **歴史的偉業**：RNIIは、GDLが誇る固体火薬推進剤の深厚な蓄積と、GIRDが有する機体空力形態および液体推進制御の最先端探究を有機的に融合させました：
  * 全軍標準配備となるRS-82およびRS-132固体航空ロケット弾、ならびに「カチューシャ」BM-13地上多連装ロケット砲システムを最終完成させ実戦配備；
  * ソ連初の有人液体ロケット推進滑空機 **RP-318** の開発に成功；
  * コロリョフ、グルシュコ、チホンラヴォフ、ポベドノスツェフら、のちのソビエト宇宙開発を率いる総設計者たちの全世代を育成・鍛錬しました。

これら初期の専門研究機関による苦闘に満ちた開拓こそが、ロシアの先駆者たちが原稿用紙の上に描いた壮大な青図を、1957年の人類初となる人工地球衛星（スプートニク1号）の軌道投入、そして1961年のユーリ・ガガーリンによる人類初の宇宙飛行という歴史的偉業へと結実させたのです！
