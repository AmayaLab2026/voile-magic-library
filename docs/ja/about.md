# 当館について：ヴワル魔法図書館
### Welcome to Voile Magic Library

> *「紙魚の微かに香る黄ばんだ頁、静謐なインクの芳香。世俗の窺い知れぬ理性の光が、ここに静かに眠る。」*

---

## ここはどのような図書館なのか？

**ヴワル魔法図書館**（Voile Magic Library）は、幻想郷の紅魔館地下深くに広がる、太陽の光の届かない浩瀚無辺な魔導大図書館にその名を由来します。魔女と学者たちの守護のもと、世界の根源を記した無数の古写本が静かに眠っています。

現代のオープンサイエンスとデジタルガーデンの文脈において、当館は **AmayaLab** により創設され、館長 **翎奈猫（Reina Neko）**（[@YuukiReina2023](https://github.com/YuukiReina2023)）により管理・運営されている、**学際的ハードコア学術および禁忌の先端知識を編纂するオープンソース・デジタル典籍館**です。

表層的な情報消費にとどまらず、**高度有機化学、精神薬理学（Psychopharmacology）、法中毒学・法科学物証、理論宇宙動力学とロケット工学史、オープンソース・インテリジェンス（OSINT）、および法規制の境界**に位置する深遠な文献に光を当てています。

---

## 収集方針と選書哲学

1. **本の香りに満ちた禁忌の知識**：  
   ヒトの認知限界、神経伝達物質受容体の構造活性相関、先端化学分子の合成誘導、深宇宙航行力学の開拓、および現代法理の変遷を追究する権威ある専門書を所蔵します。
2. **厳密を極める科学的理性**：  
   現代の分子軌道理論、厳密な可変質量解析力学、および判例・制定法を基盤とし、分子骨格や軌道方程式の背後にある客観的論理を提示します。
3. **優雅で快適な読書空間**：  
   Claude の温かみある紙面色調、角丸カプセルUI、古典的なセリフ組版を採用し、机上のスタンドライトの下で静かにページをめくるような読書体験を提供します。
