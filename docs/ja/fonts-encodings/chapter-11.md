# 第11章：ラテン文字書体の歴史的変遷と組版分類体系
**ヤニス・ハラランブス（Yannis Haralambous, Ph.D.）著**  
*『Fonts & Encodings』第367–444ページより*

---

ラテン文字の金属活字鋳造から現代のデジタルフォントに至る長大な歴史を俯瞰すると、書体の形態におけるあらゆる変遷は、人類の技術、美意識、工業生産、そして読書習慣の深層における変革と常に密接に結びついています。ルネサンス初期における古典手写本の筆致の忠実な模倣から、産業革命期における視覚的衝撃を求めた極太広告用書体（Glyph）の爆発、そして20世紀の合理主義とスイス・スタイル（国際タイポグラフィ様式）による幾何学的純粋性の極限の探求に至るまで、欧文書体は広大で深遠な視覚文明の迷宮を築き上げてきました。

この重層的かつ複雑な発展の軌跡を体系化するため、タイポグラフィ学者や理論家たちは「歴史的変遷の系譜」と「幾何学的形態の特徴」という二つの相互補完的な視点から、科学的な分類体系の構築を試みてきました。本章では、15世紀の活版印刷黎明期から現代に至るラテン書体の進化の歴史を辿り、ティボードー（Thibaudeau）、ヴォックス–ATypI（Vox-ATypI）、英国規格 BS 2961、ドイツ規格 DIN 16518、アレッサンドリーニ Codex 80（Alessandrini Codex 80）、そして現代のデジタルフォントに不可欠な PANOSE-1 10次元パラメータ分類システムを徹底的に詳解します。

# ラテン書体の歴史的変遷の系譜

## 活版印刷の発明とインキュナブラ時代（15世紀中葉）

ヨーロッパにおける金属活字印刷技術（Movable Type Printing）の時代は、ドイツ・マインツ（Mainz）の金細工師出身の発明家**ヨハネス・グーテンベルク**（Johannes Gutenberg、1398年頃–1468年）によって幕を開けました。1450年から1455年にかけて、グーテンベルクは商人ヨハン・フスト（Johann Fust）および卓越した彫刻師ペーター・シェッファー（Peter Schöffer）と連携し、銅製母型（Copper Matrix）、手鋳造活字鋳型（Hand Mold）、鉛・錫・アンチモン合金による特殊低融点鋳造合金からなる完全な活字鋳造技術体系の確立に成功しました。

グーテンベルクが印刷した不朽の金字塔が、かの有名な『四十二行聖書』（42-Line Bible、通称 **B42**、1455年頃刊）です。当時の歴史的文脈において、新興の活字印刷技術の最高目標は、機械的な冷徹さを誇示することではなく、むしろ**高価な手写本を完璧に模倣・偽装すること**にありました。当時の貴族や教会知識人は手写本に絶対的な価値を認めており、「機械刷りの産物」に強い偏見を抱いていたためです。この精巧な視覚的模倣を達成するため、グーテンベルクは文字セットを単純化することなく、中世ドイツのゴシック様式である**テクスチャー体**（Textura Blackletter）のために、実になんと290種類以上もの異なる活字母型を手彫りしました。これらには、数十種におよぶ精緻な合字（Ligature）、略記用横線付き短縮文字、そして両端揃えの行末を完全に垂直に整えるための異なる文字幅の変体活字が含まれていました。

![図版 11-1：グーテンベルク『四十二行聖書』（B42）テクスチャー体（Textura）印刷原版見本](/images/fonts-encodings/plate11-1.png)

:::

1462年のマインツの戦乱を契機として、高度な訓練を受けたドイツの印刷工職人たちはヨーロッパ各地へと離散し、これにより活版印刷の技術は瞬く間に西欧全域へと伝播していきました。

## ヒューマニズムとイタリア・ルネサンス：古典的ローマン体の誕生

印刷術がアルプス山脈を越えてルネサンスの中心地イタリア半島に伝わると、人文主義者（ヒューマニスト）たちは、中世ゲルマンの陰鬱で重厚なゴシック黒文字に強い審美的是非を抱くようになりました。彼らは、古代ローマ帝国の古典的威厳と明晰な理性を体現する新たな書体を熱望したのです。

1465年、ドイツ人印刷工の**コンラート・スヴァインハイム**（Conrad Sweynheym）と**アルノルト・パンナルツ**（Arnold Pannartz）は、ローマ近郊スビアーコ（Subiaco）の聖ベネディクト修道院にイタリア最初の印刷工房を開設しました。彼らが刻んだ活字は、ゴシックの力強い骨格と初期ローマ手写本の丸みを帯びた特徴を融合させたものであり、「セミ・ゴシック・ローマン体」（Semi-Gothic Roman）と呼ばれます。

::: tip 図版 11-2：スヴァインハイムとパンナルツがスビアーコ（1465年）で印刷したセミ・ゴシック・ローマン体見本。黒文字から古典ローマン体への過渡期における決定的一歩を示す
![図版 11-2：スヴァインハイムとパンナルツがスビアーコ（1465年）で印刷したセミ・ゴシック・ローマン体見本](/images/fonts-encodings/plate11-2.png)
*図版 11-2：スヴァインハイムとパンナルツがスビアーコ（1465年）で印刷したセミ・ゴシック・ローマン体見本。黒文字から古典ローマン体への過渡期における決定的一歩を示す。*
:::

現代に連なる西欧**ローマン体**（Roman Typeface）の不滅の規範を確立したのは、ヴェネツィアに定住したフランス造幣局の元彫刻師**ニコラ・ジェンソン**（Nicolas Jenson、1420年–1480年）でした。ジェンソンが1470年にヴェネツィアでエウセビオスの『福音の準備』（*De Evangelica Praeparatione*）を印刷した際、歴史上屈指の完成度を誇る古典的ローマン体が誕生しました。ジェンソンは古代ローマのトラヤヌス帝記念柱碑文の大文字石刻プロポーションを取り入れ、それを9世紀カロリング小文字体（Carolingian Minuscule）と調和させました。ジェンソン体（Jenson）は、線の太さの穏やかなコントラスト、緩やかな傾斜を持つセリフ、傾斜したクロスバーを持つ小文字「e」など、卓越した流動感と気品に満ちた紙面のグレーバランスを備えています。

::: tip 図版 11-3：ニコラ・ジェンソンが1470年にヴェネツィアで確立した古典的ローマン正体見本。ヒューマニスト・ローマン（Venetian / Humanist Roman）の至高の原典とされる
![図版 11-3：ニコラ・ジェンソンが1470年にヴェネツィアで確立した古典的ローマン正体見本](/images/fonts-encodings/plate11-3.png)
*図版 11-3：ニコラ・ジェンソンが1470年にヴェネツィアで確立した古典的ローマン正体見本。ヒューマニスト・ローマン（Venetian / Humanist Roman）の至高の原典とされる。*

## アルドゥス、グリッフォ、そしてオールド・ローマンの確立（15世紀末–16世紀）

15世紀末のヴェネツィアにおいて、人文主義出版人**アルドゥス・マヌティウス**（Aldus Manutius）と天才彫刻師**フランチェスコ・グリッフォ**（Francesco Griffo）の協働は、書体史の新たな幕開けを告げました。1495年、ピエトロ・ベンボの著作『エトナ山紀行』（*De Aetna*）の印刷に際し、グリッフォはジェンソン体を一段と洗練させたローマン体を彫り上げました（この書体が後にスタンリー・モリソンによって復刻され、名高い **Bembo** となります）。

グリッフォの彫ったローマン体は、大文字の高さを小文字のアセンダー（上昇部）よりもわずかに低く設定することで大文字の主張を抑え、大文字と小文字が織りなす均一で優美なテクスチャを実現しました。

![図版 11-4：フランチェスコ・グリッフォがアルドゥス・マヌティウスの『エトナ山紀行』（1495年）のために刻んだローマン体見本](/images/fonts-encodings/plate11-4.png)
*図版 11-4：フランチェスコ・グリッフォがアルドゥス・マヌティウスの『エトナ山紀行』（1495年）のために刻んだローマン体见本。コントラストが適度に高まり、セリフに幾何学的秩序が宿る。*

1499年、アルドゥスはルネサンス印刷芸術の最高峰と謳われる『ポリフィロの狂恋夢』（*Hypnerotomachia Poliphili*）を世に送り出しました。

16世紀に入ると、活版印刷の創造的中心地はイタリアからフランス・パリへと移行します。国王フランソワ1世の庇護のもと、**クロード・ガラモン**（Claude Garamond、1499年–1561年）はグリッフォの造形美を極限まで洗練させ、近代印刷の基礎となる**ガラモン体**（Garamond / Garalde）を創出しました。これと呼応するように、**ロベール・グランジョン**（Robert Granjon）が刻んだ流麗なイタリック体（Italic）が加わり、「ローマン正体＋イタリック斜体」という現代の組版における標準的なペアリング体系が確立されました。

## 過渡期ローマン体（トランジショナル）：王のローマンと理性の時代（17–18世紀）

17世紀末、フランス国王ルイ14世の命により、科学アカデミーは王立印刷所専用の書体設計に着手しました。ジャック・ジョジョン神父を議長とする委員会は、82×82の正方形方眼グリッドを用い、コンパスと定規による純幾何学的設計図面を作成しました。彫刻師**フィリップ・グランジャン**（Philippe Grandjean）は1702年、これを金属活字として実現した**王のローマン**（Romain du Roi）を完成させました。

18世紀中盤には、**ピエール＝シモン・フルニエ**（Pierre-Simon Fournier le Jeune）が活字寸法の規格化体系（ポイント・システム）を提唱し、ロココ趣味を反映した繊細で華麗な書体を発表しました。

イギリスでは、**ウィリアム・カズロン**（William Caslon、1692年–1766年）が可読性と耐久性に優れたカズロン体を刻み、英国議会およびアメリカ独立宣言書の印刷に採用されました。続いて**ジョン・バスカヴィル**（John Baskerville、1706年–1775年）は、インクの改良、表面を平滑に熱処理したウーブン紙（Wove Paper）の導入、そして垂直方向の軸線と鋭い水平セリフを持つ書体を設計し、書体デザインをトランジショナルの頂点へと導きました。

## 近代ローマン体（モダン・ローマン）と19世紀の商業的爆発

18世紀末から19世紀初頭にかけて、フランスの**フェルマン・ディド**（Firmin Didot）とイタリアの**ジャンバッティスタ・ボドニ**（Giambattista Bodoni）は、極限まで細いヘアライン・セリフと極めて太い垂直ストローク、完全に幾何学的な垂直の肥厚軸を持つ**モダン・ローマン**（Didone / Modern Roman）を完成させました。

![Figure 11-2: Didot's typeface, digitized by Jonathan Hoefler](/images/fonts-encodings/fig11-2.png)
*図 11-2：ディド体（ジョナサン・ヘフラーによるデジタル化復刻）。新古典主義の幾何学的純粋美。*
:::

::: tip 図版 11-11（Figure 11-3）：ゴールドスミス、パーキンソン、ストーンらによる ITC Bodoni。ボドニが刻んだオリジナルの鋭角性と気高き威厳を現代に再現
![Figure 11-3: ITC Bodoni, by Goldsmith, Parkinson, and Stone](/images/fonts-encodings/fig11-3.png)

19世紀の産業革命は、広告、ポスター、新聞の見出し用として、視覚的アピール力を最重視した新たな書体群を生み出しました。
* **スラブセリフ（Slab Serif / Clarendon / Egyptian）**：角張った太い四角形のセリフを持つ書体。
* **サンセリフ（Sans Serif / Grotesque）**：1816年にウィリアム・カズロン4世が発表したセリフを一切持たない書体。当初は「グロテスク（奇怪なもの）」と嘲笑されましたが、20世紀のモダン・デザインにおいて主役に躍り出ることになります。

# タイポグラフィ分類体系の理論的枠組み

## ヴォックス–ATypI 分類体系（Vox-ATypI Classification）

1954年、フランスのグラフィック理論家マクシミリアン・ヴォックス（Maximilien Vox）が提唱し、1962年に国際タイポグラフィ協会（ATypI）によって国際標準として採択された体系です。書体を以下の大分類に区分します：

1. **クラシカル（Classiques）**：手書き筆致の有機的痕跡を残す歴史的書体群
   * **ヒューマニスト（Humanes）**：ジェンソンに代表される、傾斜したセリフと緩やかなストロークコントラスト
   * **ガラード（Garaldes）**：ガラモン、ベンボに代表される、調和の取れた均斉美
   * **トランジショナル（Réales）**：バスカヴィルに代表される、垂直軸と平滑なセリフ
2. **モダン（Modernes）**：工業化と幾何学的合理性の産物
   * **ディドネ（Didones）**：ボドニ、ディドに代表される、極限の線幅対比と無ブラケット・セリフ
   * **メカニック（Mécanes / Slab Serif）**：クラレンドン、エジプシャン等の太い矩形セリフ
   * **リネア（Linéales / Sans-serif）**：セリフを持たない書体（グロテスク、ネオ・グロテスク、ジオメトリック、ヒューマニスト・サンセリフ）
3. **インスピレーション（Inspirées）**：カリグラフィ、看板、手書きに由来するもの
   * **インサイズド（Incises）**：石彫碑文に由来する書体（Optimaなど）
   * **スクリプト（Scriptes）**：筆記体、続け字
   * **マニュアル（Manuaires）**：自由な手書き筆致を模したもの
   * **ブラックレター（Fractures）**：中世ゴシック活字群

## アレッサンドリーニ Codex 80 分類法（Alessandrini Codex 80）

フランスの書体デザイナー、ジャン・アレッサンドリーニ（Jean Alessandrini）が1979年に提唱した革新的分類法です。彼は「セリフの幾何学的終端形態」に着目し、極めて直感的かつ厳密な構造分類を確立しました。

## PANOSE-1 デジタル分類測定システム

デジタル時代において、OSや組版エンジンが類似フォントを自動検索・代替（Font Substitution）するために開発されたのが、ヘューレット・パッカード（HP）社起源の **PANOSE-1** システムです。PANOSE-1 は書体を10個の厳密な1バイト数値のベクトルとして定量化します：

1. **Family Kind**（書体分類：テキスト/ディスプレイ、スクリプト、装飾、ピクトグラフ等）
2. **Serif Style**（セリフ形状：トライアングル、スクエア、ラウンド、ヘアライン、ボーン等）
3. **Weight**（ウェイト：極細から極太まで11段階）
4. **Proportion**（文字幅比率：オールドスタイル、モダン、コンデンス、モノスペース等）
5. **Contrast**（ストロークコントラスト比：無比率から極高コントラストまで）
6. **Stroke Variation**（ストローク変化：グラデュアル、ラピッド等）
7. **Arm Style**（アーム形状：ストレート、カーブ、シングル/ダブルセリフ等）
8. **Letterform**（レターフォーム：ノーマル、オブリーク、ラウンド等）
9. **Midline**（ミッドライン高さ：スタンダード、ハイ、ロー等）
10. **X-height**（エックス・ハイト比率：極小から極大まで）

この10次元空間において、二つの書体間の距離 $D$ をユークリッド距離加重平均として計算することにより、システムは指定フォントが不在の際にも、視覚的・幾何学的に最も調和する代替フォントをミリ秒単位で選定できるのです。
